# Embeddly Logo Assets

Upload your custom logo files here!

### Recommended Formats:
- **`logo.svg`** (Vector format - recommended for razor-sharp display at all screen resolutions)
- **`logo.png`** (Transparent high-resolution PNG, at least 512x256 px)

### Current Default:
The website is configured to load `assets/logo/logo.svg`.
If you upload your own `logo.png` or `logo.svg`, simply save it in this folder with the name `logo.svg` or `logo.png`.
