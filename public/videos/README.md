# Embeddly Video Assets

Place your demo, promotional, or classroom videos in this directory!

### Recommended Video File:
- **`embeddly-intro.mp4`** (H.264 MP4 format with AAC audio for universal web browser compatibility)
- **`video-poster.jpg`** (Cover thumbnail image displayed before playing)

### How It Works:
The video section in `index.html` loads from:
`assets/videos/embeddly-intro.mp4`

If you add your video here with that filename, the website will immediately play it in the interactive player and fullscreen modal! You can also paste a YouTube/Vimeo embed URL directly in the HTML if desired.
