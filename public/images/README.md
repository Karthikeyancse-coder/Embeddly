# Embeddly Image Assets

Drop your custom photos and graphics here to customize the website visuals!

### Files Used in Sections:
1. **Hero Board Image**: `hero-circuit.png` or `hero-board.svg`
   - Shows microcontroller dev board, breadboard, electronics components.
2. **About Section Lab**: `about-lab.jpg`
   - Classroom or lab setting with students building robotics / electronics projects.
3. **Photo Gallery Images**:
   - `gallery-1.jpg` : Classroom lecture / electronics theory whiteboard session
   - `gallery-2.jpg` : Student precision soldering / circuit inspection
   - `gallery-3.jpg` : Hands-on robotics test bench with students
   - `gallery-4.jpg` : Embedded development lab with oscilloscopes & power supplies
   - `gallery-5.jpg` : Microcontroller board close-up with glowing LED indicator
   - `gallery-6.jpg` : Happy cohort / graduation team group photo
4. **Enroll Section Visual**: `enroll-workbench.jpg`
   - Workbench with Arduino, multimeter, sensor modules, and electronics textbooks.

Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`.
High-quality SVG and responsive fallbacks are pre-packaged so the website looks stunning right out of the box!
